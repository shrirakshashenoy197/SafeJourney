# SafeJourney — Smart Travel Safety & Recommendation System

SafeJourney is a web-based travel safety platform designed to help users make safer and more informed travel decisions. It combines location-based information, safety factors, and personalized recommendations into a single interface.

## Features

- Safety-Based Travel Recommendations
  Provides travel recommendations based on relevant safety factors and user preferences.

- Location-Based Safety Information
  Allows users to explore destinations and view safety-related information.

- Personalized Recommendations
  Suggests suitable destinations based on user-selected preferences and requirements.

- Interactive User Interface
  Provides a clean and responsive interface for exploring destinations and safety information.

- Safety-Focused Travel Planning
  Helps users consider safety factors before choosing a destination.

- Responsive Design
  Works across desktop, tablet, and mobile screen sizes.

## How It Works

1. User enters or selects their travel preferences.
2. SafeJourney processes the selected requirements and available destination information.
3. Destinations are evaluated using safety and preference-related factors.
4. The system generates suitable recommendations.
5. Users can explore the recommended destinations through the interface.

# Getting Started

## 1. Clone the Repository

git clone https://github.com/yourusername/SafeJourney.git

## 2. Navigate to the Project

cd SafeJourney

## 3. Install Backend Dependencies

cd backend
npm install

## 4. Start the Backend Server

node server.js

## 5. Run the Frontend

Open the frontend "index.html" file in a browser, or use a local development server such as VS Code Live Server.
